How it works

  • Format. Each line is KEY=VALUE or a # comment. Anything else is rejected before writing — a malformed file stops xdev from starting.
  • Backup. Every save keeps the previous file next to it as xdev.env.bak.
  • Restart. Saving never restarts the service you're using. Afterwards run sudo systemctl restart xdev.
  • Plain HTTP. XDEV_DISABLE_HTTPS_REDIRECT=true serves sites without the HTTPS redirect, for previewing on alternate ports during a migration. Set it back once you're on 80/443.
  • Reference. deploy/xdev.env.example in the repo, or xdev help.
